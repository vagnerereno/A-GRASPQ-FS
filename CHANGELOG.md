# Changelog

## 1.0.0

- Added production-ready `agraspqfs` package.
- Added `AGraspQFeatureSelector`, a scikit-learn compatible transformer.
- Added presets: `fast`, `balanced`, `robust`, and `paper`.
- Added cache, evaluation budget, time budget and early stopping.
- Added CLI command `agraspqfs`.
- Added examples, API documentation and tests.
- Added MIT `LICENSE`, `CITATION.cff`, citation guide and Zenodo metadata.
- Added GitHub Actions workflows for testing/building and PyPI Trusted Publishing.
- Added contributing, security, code of conduct and release checklist files.
