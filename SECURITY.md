# Security Policy

A-GRASPQ-FS is a research-oriented Python library for feature selection. It does not intentionally process untrusted code, execute remote scripts, or open network connections.

## Supported versions

Security fixes are intended for the latest released version.

| Version | Supported |
|---|---|
| 1.x | Yes |
| < 1.0 | No |

## Reporting a vulnerability

Please report suspected vulnerabilities privately to the maintainers instead of opening a public issue. Include:

- affected version;
- minimal reproduction steps;
- operating system and Python version;
- expected and observed behavior.

For datasets from third parties, users are responsible for ensuring that data is legally and ethically usable.
